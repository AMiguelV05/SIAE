# SIAE
SIAE (Sistema Integral de Asistencia Estudiantil). Monorepo creado para la elaboración del proyecto modular iniciado en el ciclo 2026B, planeado para concluir en el ciclo 2027B. Constituido por un dashboard web, una aplicación móvil, algoritmos de Machine Learning para predicción de demanda, integración con LLM e implementación de un RAG.
